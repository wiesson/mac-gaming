# Diablo IV profile

**Route:** Battle.net in a matched custom Wine 11 based runtime. This profile is based on one successful M3 Max setup. It is not yet a reproducible clean installer: several engine and renderer components must be kept together.

- [Setup and exact tested components](../../docs/setup.md)
- [Graphics and audio](../../docs/settings.md)
- [Troubleshooting](../../docs/troubleshooting.md)
- [Battle.net write-copy crash investigation](../../docs/technical-notes.md)

The agent should inventory an existing Diablo installation before proposing changes. Use the documented components as a reference, preserve any working runtime, and verify Battle.net sign-in, game launch, sound, and exit on this machine. Do not transplant a single DLL from an unrelated engine into a working bundle.
